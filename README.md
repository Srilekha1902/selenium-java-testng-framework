# Selenium Java TestNG Framework

This repository contains two parts of my QA automation learning journey:

## selenium-testng-pom-framework
A Selenium WebDriver automation framework built using:
- **Java**
- **TestNG** for test execution and assertions
- **Page Object Model (POM)** for maintainable test structure

Automates key user flows on [SauceDemo](https://www.saucedemo.com/):
- Login (valid/invalid scenarios)
- Adding products to cart
- Navigating to checkout and completing purchase flow

## core-java-practice
Core Java fundamentals practice covering OOP concepts (classes, constructors, inheritance, polymorphism), collections, loops, and exception handling.

---
**Tech stack:** Java, Selenium WebDriver, TestNG, Maven, Page Object Model
